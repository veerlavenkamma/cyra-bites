# 🌟 About Cyra Bites

**Cyra Bites** is a modern cute food delivery mobile application designed with a soft aesthetic UI, cozy animations, and a happiness-oriented experience.

The app combines:

* 🍜 Realistic food delivery experience
* 🎨 Minimal premium UI/UX
* ✨ Soft modern animations
* 💛 Cozy emotional design
* 🚀 Fast & smooth interactions

Inspired by premium food delivery apps like **Swiggy**, **Zomato**, and **Uber Eats**, but redesigned with a softer, cuter, and more aesthetic personality.

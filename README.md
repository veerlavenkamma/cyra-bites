# 🌟 About Cyra Bites

**Cyra Bites** is a modern food delivery application designed with a soft aesthetic UI, cozy interactions, and a happiness-oriented user experience.

The app combines:

* 🍜 Realistic premium food delivery UI
* ✨ Smooth modern animations
* 💛 Cozy pastel aesthetics
* 🚀 Fast ordering experience
* 🎨 Minimal futuristic interface

Inspired by apps like Swiggy, Zomato, and Uber Eats — but redesigned to feel softer, cuter, and emotionally comforting.
